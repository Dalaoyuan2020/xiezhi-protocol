# 灋廌覈鑒 · 学术信誉链使用与演示指南

更新：2026-10-08。默认入口是带彩色搜索框的首页；工作台与首页共用当前服务和数据接口。

## 启动与部署

需要 **Node.js 24.13.0 或更新版本**，实时学者核验还需要 Python 3。在仓库根目录运行：

```sh
npm ci
npm start
```

保持服务终端运行，访问地址以启动日志为准。本机当前为 `http://127.0.0.1:8890`，首页为 `/ui/`。请运行完整 Node 服务；单独打开 HTML 或使用静态文件服务无法提供检索、邮箱、认领和交易核验接口。

数据源与 SMTP 在独立管理页 `/admin/sources/` 配置，使用服务器上的管理访问口令。密钥保存在服务端。自己的域名、HTTPS、持久磁盘、迁移与备份步骤见 [应用运行与部署说明](../aia/app/README.md)。

## 首页与手机操作

- 在 `/ui/` 输入姓名、拼音、ORCID 或 OpenAlex 作者编号；姓名查询后可选填学校、研究所或简称。有有效机构的同类姓名候选优先展示，编号精确匹配仍优先。
- 右上方方块菜单提供「极简模式」「投影模式」「切换工作台」等入口。极简模式只显示搜索框和小型退出控件，搜索结果、单位筛选与错误提示照常显示；开关会保留到下次访问。
- 点击极简页右上角的小图标回到完整首页。键盘可用 Tab、Shift+Tab、Enter 操作。
- 手机可直接使用相同网址；320px 起适配，输入框与退出按钮随可视高度调整。候选、认领选项和后续步骤可纵向滚动，无需切换桌面版。
- `/workbench/` 是另一套工作视图。切换入口在方块菜单内，默认首页保持彩色搜索页面。

## 本地与自部署服务的真实学者五步流程

线上 <https://aia.hai.college/> 当前发布范围是只读检索、核验与评分。以下完整流程描述仓库代码的可配置能力；线上真实邮件、社区结算同步上链、投稿押金与降低门槛仍属规划。SMTP 是否可用，以当前部署配置与实际发送结果为准。

1. **检索与选择**：在首页搜索，结合单位、研究方向和 ORCID 选择候选。进入 `/live/` 后观看 Agent 检索与交叉核验过程。公开数据可能命中缓存，来源、时间和错误以页面为准；不会用模拟档案替代失败结果。
2. **查看核验报告**：阅读灋廌学术分、证据与局限。当前实时学术分规范为 **v2.1**（链上标识 `checkup-v2`），范围为 **350–950**；分数反映公开资料可核查程度，不是人品或学术真实性裁决。典型案例页的历史快照必须按其标注的规则版本理解，不能直接与实时分数混算。
3. **逐篇认领**：继续认领，对每篇材料选择「是我的」「不是我的」或「待核对」，复核最后汇总。这里记录的是用户声明。
4. **邮箱验证**：输入自己可接收邮件的邮箱，发送并填写真实 SMTP 验证码。未配置或发信失败会明确提示；真实验证码不在网页上回显。**验证邮箱控制权不等于证明论文作者身份或机构身份。**
5. **确认与存证**：核对材料后选择存证方式。公开材料完成真实邮箱验证后，可连接自己的钱包，在 **BOT Chain 主网 677** 签名并支付 Gas。服务端先返回未签名交易，再独立读取节点核对发送人、合约、参数、事件和区块；只有确认成功才签发主网凭证并展示盖章与回执。待确认或失败会显示对应状态，不能把动画当作上链证据。

已收到交易号时，刷新或重试继续核验该笔交易；勿仅因等待时间较长而重复发送。凭证可下载并重新验证，真实主网记录可通过回执中的区块浏览器链接查看。认领或盖章**不会自动提高学术分或发放廌点**。

主网流程需要有效合约配置、可访问的 BOT RPC、支持 EVM 的钱包及用户自己的 Gas。服务端不持有主网私钥，不代签、不自动广播。

## 徐林森互动演练与本地链

从首页「徐林森 · 体验认领、邮箱验证与盖章」进入，或访问 `/live/?demo=claim-xu`。

这个入口使用**明确标注的模拟论文材料**，与首页检索得到的真实公开候选分开。可以完成逐篇选择、模拟邮件预览、最后确认、盖章、区块增长和凭证下载。存证运行在本地 Ganache EVM 链，**Chain ID 1337**；区块与交易由本地节点产生，不是 BOT 主网交易，也不用于证明同名真人的论文归属。

模拟案例只走本地链。公开材料也可以主动选择本地体验，但仍须完成真实邮箱验证。邮箱验证、上链结果和模拟状态分别标注，不能互相替代。

## 论文体检与机构查询

- **论文体检 `/paper/`**：上传 PDF、Markdown、TXT 或 ARA ZIP。查看 `PAPER.md`、`logic/`、`src/`、`trace/`、`evidence/` 是否齐备，以及主张是否指向证据。普通 PDF 会列出缺失材料；页面提供两份虚构 ARA 样例供下载、修改和重传，并可下载检查报告。检查不执行上传代码，也不授予官方 ARA Seal 或裁定科研真假。
- **论文检索 `/ui/papers.html`**：查询已接入的学术源，结果保留来源与去重信息。来源未配置、限流或不可用时按页面状态处理。
- **机构查询 `/ui/org.html`**：区分虚构快照与真实链上只读记录，查看投稿、结案、认领等行为时间线。疑似一稿多投等提示需要结合可信登记方和实际投稿状态复核，不能仅凭提示认定学术不端。
- **知行社 `/workspace/`**：账号、研究材料、审阅、独立验收与社区功能见 [应用说明](../aia/app/README.md)；与公开认领会话是不同的权限体系。

## 演示前检查

1. 在实际访问域名打开首页，完成一次真实搜索，确认单位筛选及 Agent 报告可读取。
2. 需要真实邮件时先配置 SMTP；演练只用自己控制的邮箱。模拟验证码预览只在明确标注的模拟案例使用。
3. 需要主网演示时准备钱包与 Gas，检查钱包显示 BOT Chain 677；以真实回执为成功依据。
4. 需要无费用演练时使用徐林森模拟入口，说明本地链 1337，并验证下载的凭证。
5. 更新部署时保留完整运行数据目录；它保存账号、认领会话、凭证、本地链及加密配置，不随新版代码清空。
