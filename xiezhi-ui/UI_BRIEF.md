# UI 设计任务书：学术体检（Scholar Checkup）

> 2026-10-07 · 发起人：致远 · 产品方向见 [产品设计草案](../product/2026-10-07_scholar_checkup_design.md)
> 目标：明天下午提交前，一个**能在大屏上演示、有黑客松感、有动画**的前端。先用假数据做，后端好了再接。

## 一、主题（要写在 UI 上）

**产品名**：学术体检 · Scholar Checkup（可再议）

**主标语**：身份先认清，分数能追查，规则钉上链。

**副标语**：输入一位学者，30 秒拼出 TA 的公开学术档案，给出每一分都能点开证据的「可核查度」。

**故事开场**（首页小字或加载页）：
> 「我查了一下自己。我的墒情论文，挂在一位上海交大燃烧学者的名下；我自己的档案里，只有 2 篇。」

## 二、四个画面（一条线走完）

### ① 首页：搜索
- 大输入框：ORCID，或「姓名 + 单位」
- 下方 4 张案例卡片可一键点：致远本人 / Karpathy / 何恺明 / 虚构灌水号
- 背景：缓慢漂浮的论文节点 + 网格线，右上角滚动的区块号（假的，比如 `BOT Chain · Block #25,592,150`）

### ② 检索中：动态组建知识库 ⭐ 主动画，全场高光
按顺序演出，总长 6–10 秒：
1. **终端日志逐行打出**：`> 连接 OpenAlex…` `> 找到 5 篇论文` `> 解析 ORCID…`
2. **知识图谱长出来**：学者是中心节点，论文一颗颗飞入挂上去，按研究领域上色；单位、合作者节点再连上
3. **致远案例的反转**：画面上同时出现**两个档案**——致远本人（2 篇管道机器人）和上海交大燃烧学者（5 篇，其中 1 篇墒情论文颜色不一样、在闪）。弹出 ⚠️「检测到论文错挂 · 请本人认领」
4. 图谱缩到左侧，进入打分

### ③ 体检卡
- 大号总分（0–100 数字滚动上去），旁边是**置信度**标签（低 / 中 / 高）
- 五维雷达图，逐维画出来
- 五条进度条依次填满，每条后面是证据小字，**可点开**（链到 OpenAlex 原始记录）
  - 身份清晰度 / 撤稿与更正 / 开放程度 / 同领域影响力 / 产出节奏
- 显眼的小字声明：**「可核查度 ≠ 人品分。它衡量公开记录能支撑多少信任。」**
- 虚构灌水号卡片必须带「虚构样例」水印

### ④ 上链收据
- 「生成收据」按钮 → 哈希逐字打出 → 区块确认动画（打勾 + 区块号）
- 收据内容：学者 ID 哈希、数据快照哈希、规则版本 `v0`、总分、时间
- 「在浏览器中查看」按钮（链接先留空，等合约部署后填）
- 「本人认领」按钮：模拟钱包签名 → **那篇墒情论文从错的档案飞回致远档案** → 分数重算的动画

## 三、黑客松视觉

- 深色底，霓虹青 / 绿点缀，等宽字体做数据和哈希
- 轻微扫描线或网格，数字滚动，打字机效果
- 要「酷」，但**字要看得清**：投影仪上 3 米外能读
- 手机宽度也能看（评委可能扫码）

## 四、技术约定（方便后面接后端）

- **纯静态**：一个 `index.html` + JS + CSS，双击或 `python3 -m http.server` 能跑，不要构建工具
- 动画库可用 CDN：D3（图谱）、GSAP（时间线）或纯 Canvas，任选
- **数据只从 [`../product/mock_cases.json`](../product/mock_cases.json) 读**，字段：
  - `case_label` `name` `institutions` `orcid` `works` `cited_by` `h_index`
  - `score` `confidence` `dims`（五维，值是「分数/20（证据说明）」字符串）
  - `note`（这条案例的看点，可显示在卡片角落）
- 知识图谱的节点数据 mock 里没有，先自己造假数据：致远案例 = 本人档案 2 篇管道机器人 + 错挂在别人档案里的 1 篇墒情（见 mock 里 `misattributed` 字段）；其余随意
- 代码放 `aia/ui/` 下，不要改 `aia/commission-demo/` 和 `aia/demo/`
