# 灋廌覈鑒 · Xiezhi · 默认搜索首页

本目录作为默认 `/ui/` 搜索首页，保留彩色流转搜索框、圆形箭头、1.8 秒印章旋转和方块菜单。右上角方块菜单内的“切换工作台”进入 `/workbench/`（`新ui/`）；工作台左上角可返回本页。两套共用服务端接口、账号数据和密钥配置，切换保留姓名、单位与网络。`/classic/` 兼容链接重定向到本页。历史截图和 DEMO_GUIDE 仅供参考。

## 本地运行

需要 Node.js 24.13.0+，在仓库根目录运行：

```sh
npm ci
npm start
```

- 首页：<http://127.0.0.1:8890/ui/>
- 典型案例：<http://127.0.0.1:8890/ui/cases.html>（首页右上角菜单进入）
- 体检卡：<http://127.0.0.1:8890/ui/checkup.html?case=A5126602136>
- 机构查询：<http://127.0.0.1:8890/ui/org.html>
- 账号与科研协作：<http://127.0.0.1:8890/workspace/>

不要仅对本目录启动静态文件服务器：公开案例、合约 ABI 和部署清单由应用从 `aia/product`、`aia/chain` 按白名单提供。本目录的 `product/` 是队友提交时的历史副本，不作为运行时数据源，也不要使用其中的旧评分脚本。

## 已接入

- 首页专注学者搜索；四个案例移至独立案例页，右上角菜单连接个人体检、机构查询和科研协作。
- 重名候选、五维证据卡、个人核查任务和收据。
- 主网／测试网只读合约查询、积分余额与流水、机构投稿与结案记录。
- 保留最新积分规则（points-v0），仅显示真实链上记账，点击本地任务不会增加余额。
- 旧 `card.html?id=...` 和 `/legacy/ui/...` 地址保留档案、网络与视图参数后转入新版。
- 原有账号、材料、审阅及独立验收保留在 `/workspace/`，不受公开 UI 替换影响。

## 数据版本

首页姓名、ORCID 和单位筛选通过服务端 `/scholar-api/search` 查询 OpenAlex，候选进入 `/live/` 实时核验；文献页通过服务端查询已接入的学术来源。典型案例及其五维体检证据仍来自 `aia/product/mock_cases.json` 的公开快照，页面应明确区分。体检卡为 **checkup-v0（0–100 分）**；主网最新登记为 **checkup-v2（350–950 分）**。收据依据链上规则版本解码 v2，不能将旧版五维快照冒充成 v2 的评分证据。

当前仓库已包含 BOT 主网 677 的行为合约和积分合约配置，详见 [主网记录](../aia/chain/MAINNET.md)。默认检查主网部署；`?network=testnet` 明确读取测试网 968，显式选择的网络不会自动换成另一条链。RPC 不可用会显示错误，不能把快照显示成已上链。

虚构案例不会发起真实主体积分查询。本地认领、任务导出和快照收据不广播交易；主网上的演示投稿仍应按演示数据理解，不指控现实研究者。积分发放方、证据指纹和流水均需分别核对；无证据指纹的事件会明确标注。

## 验证

在仓库根目录：

```sh
npm test
npm run test:ui
npm run test:legacy
```

前端测试覆盖候选搜索、评分版本、结案判定、部署网络、链数据边界、积分以及任务规则。服务端测试覆盖新版入口、旧链接跳转、资源白名单和账号 API 隔离。不向链上发送测试交易。

后续页面修改在本目录进行。链积分 CLI 与页面共用 `points-rules.js`，修改规则时必须同时验证这两处的行为。
