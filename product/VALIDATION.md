## 二、v1 规则

各项 0–1，最后乘 100：

```
原始分 = 0.25·身份 + 0.35·同行认可 + 0.15·开放 + 0.25·产出节奏
证据权重 w = 论文数 / (论文数 + 10)
收缩后 = 0.5·(1 − w) + 原始分·w          ← 论文越少，越接近「证据不足」的 50
总分   = 100 · 收缩后 · 诚信系数
诚信系数 = max(0, 1 − 10 × 撤稿率)        ← 撤稿率 10% 即归零
```

- **身份**：ORCID 0.4 + ORCID 官方雇主与档案单位一致 0.3 + 研究领域一致性 0.3
- **同行认可**：领域归一化引用 FWCI 中位数，`0.5 + 0.25·log2(FWCI)`，截到 0–1；**无引用记 0**（v0 这里没有引用也不扣）
- **开放**：开放获取比例
- **产出节奏**：单年最多 ≤20 篇为 1；20–50 篇线性降到 0.3；>50 篇为 0

## 三、怎么证明规则可信（不是拍脑袋）

| 验证方式 | 做法 | 状态 |
|---|---|---|
| 对照组 | 已知干净的高影响力学者应高分，已知大规模撤稿的学者应最低 | ✅ 上表，v0 不通过，v1 通过 |
| 单调性 | 撤稿增加 → 分数只降不升；引用增加 → 分数只升不降；证据增加 → 向原始分靠拢 | ✅ 由公式保证（各项单调） |
| 可复算 | 同一快照 + 同一规则版本 → 同一分数；快照哈希和规则版本上链，任何人可复算 | ✅ 已实现 |
| 统计检验 | 用 Retraction Watch 全量撤稿名单作标签，抽样计算区分度（AUC） | 📌 路线图 |

## 四、数据从哪来、怎么拿到「有效」的数据

| 来源 | 拿到什么 | 可信度 |
|---|---|---|
| ORCID 官方记录 | 本人填写的雇主、作品 | 本人声明（需本人登录授权才算核验） |
| OpenAlex 作者档案 | 算法归并的论文、引用、FWCI、撤稿标记 | 覆盖广，但会**错挂、合并**（致远案例） |
| 两者交叉 | ORCID 作品 vs OpenAlex 作品的差集 | 差集就是「疑似错挂 / 疑似漏挂」，交给本人认领 |
| 摘要与开放全文 | OpenAlex 摘要倒排索引、开放获取 PDF 链接 | 可用于后续的内容级检查（主题是否一致、方法与结论是否对应） |
