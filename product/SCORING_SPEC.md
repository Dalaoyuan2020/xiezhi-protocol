# 灋廌学术分 · 评分体系定稿 v2.1（2026-10-07 21:00 冻结）

> 致远：「今晚固定评分体系，后面沿着它一路走到黑，对它负责。」
> **本文件是唯一权威版本**。以后任何改动都要升版本号（v2.2…），旧版本的链上记录永远保留、可复算。
> 代码：`aia/product/checkup.py --v2`；链上规则标识：`checkup-v2`。

## 1. 一句话

学者第一次进来，用**公开数据**算出一个 350–950 的学术分；之后靠**链上行为**（投稿结案、审稿、复现、核对）慢慢变化。分数说的是「公开记录能支撑多少信任」，不是人品分。

## 2. 五个维度

| 维度 | 权重 | 算什么（0–1） | 数据 |
|---|---|---|---|
| 学术身份 | 0.20 | ORCID 0.4 + ORCID 官方雇主与档案单位一致 0.3 + 研究领域一致性 0.3 | ORCID、OpenAlex |
| 学术履历 | 0.30 | 同行认可 0.6（领域归一化引用 FWCI 中位数，`0.5+0.25·log2(FWCI)`，无引用记 0）+ 成果积累 0.4（`ln(1+n)/ln 51`，50 篇封顶） | OpenAlex |
| 学术习惯 | 0.20 | 开放获取比例 0.5 + 产出节奏 0.5（单年 ≤20 篇为 1；20–50 篇线性降到 0.3；>50 篇为 0） | OpenAlex |
| 学术履约 | 0.20 | 首次进入为中性 0.5；之后由链上行为更新（见 `plan/RULES.md` §2） | 本链 ActionRegistry |
| 合作网络 | 0.10 | 路线图（合作者本身的可信度）；当前记中性 0.5 | — |

## 3. 公式

```
公开部分 = (0.20·身份 + 0.30·履历 + 0.20·习惯 + 0.10·合作) / 0.80
证据权重 w = 论文数 / (论文数 + 10)
收缩后公开部分 = 0.5·(1 − w) + 公开部分·w          ← 论文少 → 向中性收缩
综合 = 0.80·收缩后公开部分 + 0.20·履约               ← 履约不收缩（链上行为是实打实的证据）
撤稿平衡系数 = 1 − min(0.7, 3 × 撤稿率)               ← 不是一票否决，最多扣 70%
chain_value = round(100 × 综合 × 撤稿平衡系数)         ← 链上只存这个 0–100 整数
灋廌学术分 = 350 + 6 × chain_value
```

## 4. 档位

| 档位 | 分数 | 权益 |
|---|---|---|
| 极好 | 830–950 | 审稿专家，带新审稿人 |
| 优秀 | 750–829 | 期刊优先审稿；可接审稿挣积分 |
| 良好 | 680–749 | 投稿免费 |
| 中等 · 证据不足 | 600–679 | 新人默认档；投稿免费 |
| 一般 | 500–599 | 投稿押 10 积分（可退），同时在审 ≤2 |
| 待提升 | 350–499 | 投稿押 20 + 交 10 积分，同时在审 ≤1 |

零论文账号（未认领任何本人论文）按「待提升」档投稿，不发新手积分。积分规则见 `plan/RULES.md`（v1.2）。

## 6. 已知局限（如实写）

1. **首次进入的分数集中在 600–800**：合作网络和履约两维（共 30%）首次都记中性，论文少的人又会向中间收缩。350–950 的两端主要由撤稿和之后的链上行为拉开。这是有意的：**第一次见面不轻易下结论**。
2. 依赖 OpenAlex 的归并质量；错挂、合并要靠本人认领纠正（ORCID 授权登录在路线图）。
3. FWCI 只覆盖部分论文；新论文还没有引用，会让新人的「同行认可」偏低。
4. 合作网络维度尚未实现。
