# 廌点白皮书 v0.1

**灋廌覈鑒 · 学术信誉链的贡献记账**
Know & Act（知行合一）· 汉客松 S1 · ETH Wuhan 2026 · 2026-10-07

---

> **一句话**：我们用「**廌点**」记账：做了可验证的事就发，**不能转让、不能兑现、不能买卖**。它是链上记账，不是虚拟货币。

**廌**是獬豸的本字。传说獬豸见到不正直的人，就用独角去顶。廌点图案上那只独角小兽就是它。廌点和协议名「灋廌覈鑒」一脉相承：**分数记录你是什么样的学者，廌点记录你为学术社区做了什么。**

---

## 1. 为什么需要廌点

AI 让写论文变得很容易，审稿人的注意力却没有变多。ICLR 2026 收到约 1.9 万篇有效投稿；大会的办法是一刀切：每人每年最多 20 篇。可工作室会找更多人互相挂名，**篇数能分摊给别人，信誉分摊不了。**

学术圈真正缺的，不是又一个排行榜，而是三件没人愿意白干的事：

| 稀缺的事 | 现在谁在做 | 问题 |
|---|---|---|
| **审稿**（Attention） | 志愿者 | 累、没回报，好审稿人被灌水稿耗尽 |
| **复现**（Act） | 几乎没人 | 发不了论文，没有动力 |
| **核对与纠错**（Act） | 几乎没人 | 论文挂错人、参考文献不存在，没人管 |

廌点就是给这三件事**记一笔账**：谁做了、做得对不对、证据在哪，都写在链上，谁都能查。

## 2. 两本账：知与行

我们队叫「知行合一」，协议里正好有两本账，**绝不混用**：

| | **灋廌学术分**（知） | **廌点**（行） |
|---|---|---|
| 记什么 | 你的公开学术记录有多可信 | 你为社区做了多少可验证的事 |
| 范围 | 350–950，六个档位 | 从 0 开始累计，可用可扣 |
| 怎么来 | 公开数据（OpenAlex、ORCID、Crossref）+ 链上履约记录，按公开规则计算 | 只有一条路：**做了可验证的事** |
| 能干什么 | 决定档位：投稿要不要押金、能不能接审稿 | 交押金、交低档投稿费，以后兑换实物激励 |
| 能不能买 | 不能 | **不能**（合约里没有转账功能） |
| 互相影响 | **廌点余额不进学术分公式**，花多少廌点都买不到分 | 档位决定你能接哪些任务 |

打个比方：学术分像**体检报告**，廌点像**献血证 / 志愿服务时长**。体检报告买不来，献血证也不能转给别人，但两样都能让你在需要时被优先照顾。

## 3. 怎么挣

规则版本 `points-v0`，已在合约与代码中实现（✅）；带 📌 的是已定规则、待上线。

| 做了什么 | 廌点 | 条件 |
|---|---|---|
| **新手保护**：第一次个人上链（盖红章） | +20 | 一次；认领的档案里**至少有 1 篇论文**才发（零论文小号拿不到） ✅ |
| **认领并纠正一篇错挂论文** | +5 | 交叉验证「高」置信 + 单位邮箱验证；其余先挂起，复核通过再发（每次最多 3 篇） ✅ |
| **每日核对**：这篇论文是不是这位作者的？这条参考文献存在吗？ | +3 / 题 | 同题多人比对一致；混入已知答案的暗题；**每月最多 30** 📌 |
| **审稿被采纳** | +5 | 学术分「优秀」（750）及以上才能接 📌 |
| **复现一个主张** | +8 | 独立复跑对得上（结果不一致但工作合格也给） 📌 |
| **日常运维**（数据纠错等） | +2 | 📌 |

每一笔都带**原因编号 + 证据指纹**：例如认领的证据是那份「认领凭证」的哈希，任何人可以拿凭证原文重算核对。

## 3.5 社区里看得见的廌点

- **金币落下**：认领盖章、任务验收通过的那一刻，一枚獬豸金币从天而降，落到你的廌点余额上，旁边弹出「+N 廌点」
- **彩蛋 · 廌点雨**：查到学术分 750 以上的学者时，天上下一阵金币雨，庆祝社区来了一位能审稿的人
- 金币雨**只是动画，不额外发廌点**。廌点只有一条来路：做了可验证的事

## 4. 怎么用

廌点只有两个去处：**为自己的投稿负责**，以及**兑换社区提供的激励**。

| 档位（学术分） | 投稿 | 押金（廌点，规范结案全额退回） | 其他 |
|---|---|---|---|
| 极好 830+ / 优秀 750+ | 免费 | 0 | 期刊优先；可接审稿挣廌点 |
| 良好 680+ / 中等 600+ | 免费 | 0 | 新人默认在「中等 · 证据不足」 |
| 一般 500+ | 免费 | 10（可退） 📌 | 同时在审最多 2 篇 |
| 待提升 350+ | 投稿费 10（不退） ✅ | 20（可退） 📌 | 同时在审最多 1 篇 |

押金规则 📌：结构预检不过 → 退一半；**确认一稿多投 → 全部没收**；正常结案（录用或拒稿）→ 全额退回。
兑换 📌：路线图里可换实物激励、审稿费减免、快速通道等，**由合作期刊与机构出资**（见第 7 节）。

**自圆其说的那条线**：诚实的人（新人、大牛）**一分廌点都不用花**；想灌水的人，每多投一篇都要先付出行动。篇数不封顶，**注意力只花在过了门槛的稿子上**。

## 5. 防作弊：不变量 + 12 个月模拟

我们没有只靠「感觉合理」，而是做了数学核验（可复跑：`python3 aia/product/points_model.py`，固定随机种子）。

**对任何行为都成立的六条性质**

| # | 性质 | 结果 |
|---|---|---|
| A1 | 廌点余额永不为负（合约 `spend` 要求余额足够） | ✅ |
| A2 | 廌点买不到学术分（余额不进分数公式） | ✅ |
| A3 | 刷每日任务涨分有上限：每月最多 +6 分 | ✅ |
| A4 | 撤稿压低天花板但不归零：撤稿率 10% → 最高 770 | ✅ |
| A5 | 单调：履约越好分越高，撤稿越多分越低 | ✅ |
| A6 | 廌点不能转让（合约没有 transfer / approve，自动测试断言） | ✅ |

**12 个月蒙特卡洛模拟**（新人 100、大牛 20、失信者 10、灌水者 10、零论文小号 50）

| 规则 | 失信者 + 灌水者 + 小号 占走的审稿注意力 |
|---|---|
| 一刀切（每人每年 20 篇） | 63% |
| 我们的第一版规则 v1 | 80%（核验发现比一刀切还差，已修正） |
| **现行规则 v1.2** | **30%**；零论文小号 **0 篇**进入审稿 |

v1 → v1.2 修掉的四个问题：小号漏洞、审稿门槛够不着、新人涨不动、廌点通胀。详见 `aia/product/POINTS_VALIDATION.md`。

**还没被覆盖、如实说明**：廌点仍有净增长，建议加 **12 个月有效期**；一稿多投的识别率取决于接入期刊的数量；多人勾结互审需要利益冲突回避规则。

## 6. 链上怎么记

合约 **`PointsLedger`**（Solidity，开源）只有两个写入动作：

- `award(subject, amount, reason, evidence)`：发廌点
- `spend(subject, amount, reason, evidence)`：扣廌点，余额不够就失败

**没有** `transfer`、`approve`、交易、提现，也不对接任何交易所。`subject` 是 `keccak256("openalex:<作者编号>")`，链上**不放姓名、单位、邮箱**。只有登记在册的发放方地址能写，每一笔都留下事件（原因、证据指纹、发放方、余额），谁都能查。

| 网络 | 合约 | 用途 |
|---|---|---|
| **BOT Chain 主网**（Chain ID 677） | PointsLedger `0x28B2af15386C0D65D5427d5b81bEe485D4edD60A`；ActionRegistry `0xA0853161002Af018225419324560FCE9CD9b10eD` | 正式记录，已有真实交易（新手保护 +20、认领错挂 +5 等，见 `aia/chain/MAINNET.md`） |
| BOT Chain 测试网（968） | 同一份代码 | 开发测试 |
| 本地模拟链（1337） | 同一份代码 | 现场演示：不花钱、秒确认 |

## 7. 钱从哪来

**我们从不卖廌点，也不靠廌点赚钱。**

| 谁 | 付不付钱 | 得到什么 |
|---|---|---|
| **学者** | **免费** | 体检、认领、盖章、挣廌点 |
| **期刊 / 会议** | 付费 | 收稿登记 + 一稿多投查询；附「可信报告」的稿子省掉筛查功夫 |
| **高校 / 基金 / 招聘方** | 付费 | 批量核验、接口调用（查档案是否错挂、履约记录） |

这和 ORCID 靠机构会员费运转、Crossref 查重「先贡献数据才能用」是同一个思路。机构付的钱用来：① 支付上链的手续费和服务器；② 出资做廌点的兑换激励（审稿费减免、实物奖励）。**期刊愿意出这笔钱，是因为高信誉作者和认真审稿人替它省了筛查成本。**

具体价格还没有定，要和首批期刊一起谈；白皮书里不写拍脑袋的数字。

**飞轮**：期刊登记 → 数据变多 → 查询更准 → 更多期刊加入、更多作者认领 → 低分者做核对修数据 → 数据更准 → ……

**反面教材**：有学术平台曾发行代币奖励审稿，代币价格大幅下跌后激励随之失效。我们的结论是：**激励要绑在人和行为上，不能绑在一个会涨跌的价格上。**

## 8. 我们承诺不做的事

1. **不发行**虚拟货币或代币，不做 ICO、IEO、空投，不募资
2. 廌点**不能转让、不能兑现、不能买卖**，不提供任何交易或兑换成法币、虚拟货币的渠道
3. **不卖分、不卖廌点**：任何人都不能花钱买学术分或廌点
4. 链上**只存指纹和分数**，不存个人资料；邮箱只存哈希
5. 规则**公开、带版本号**；改规则就换版本号，**不改历史记录**

以上符合国内关于防范虚拟货币交易炒作风险的监管要求（如 2021 年九月人民银行等部门发布的相关通知）：廌点是服务内的贡献记录，不具有货币属性。

## 9. 治理

- **规则版本化**：每次评分、每笔廌点都带规则版本号上链，谁都能按同一版本复算
- **发放方名单**：只有登记的发放方地址能写入；接入的期刊、平台需公开自己的地址
- **复核与申诉**：凭证可重算核对；有争议的认领进入「待复核」，复核通过才发廌点
- **参数可调**：20、30、750、830 等是第一版参数，模拟脚本改参数即可重跑验证
