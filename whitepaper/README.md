# AIA 社区白皮书（正式版）

**[AIA_COMMUNITY_WHITEPAPER.md](AIA_COMMUNITY_WHITEPAPER.md) · [PDF](AIA_COMMUNITY_WHITEPAPER.pdf)**：《AIA 社区白皮书》AIA Commons Whitepaper（灋廌覈鑒 · 獬豸协议），2026 年 10 月正式版，唯一有效版本。
