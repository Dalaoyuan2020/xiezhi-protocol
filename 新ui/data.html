数据说明

每一类数据，都有明确的出处与用途。

当前使用的数据

搜索来自随项目保存的 OpenAlex 公开快照，包含五个同名候选，以及与四个演示案例合并的档案数据。快照标记日期为 2026-10-07；不是实时全库检索。

候选快照 JSON ↗评分快照 JSON ↗机构虚构数据 JSON ↗

公开库可能存在同名错挂或资料不全。未评分候选只展示档案；未收录人物不会生成分数。SYNTHETIC 案例和机构页虚构快照都有独立标识，不对应真实主体。

浏览器中的本地资料

  • 读者返回上下文使用当前标签页的 sessionStorage，保存查询、候选及返回位置。
  • 审稿人和投稿人分别在 localStorage 中保留一份草稿和一份上次覆盖前的原文备份；不会自动保存，也不同步到账号或其他设备。
  • 修改后须手动保存；覆盖前保留一份原文备份，备份失败则停止覆盖。保存需要浏览器支持 Web Locks，不支持时仍可编辑和导出。
  • JSON 导入先预览，再进入编辑区，不会自动覆盖已保存稿。可导出当前编辑或已保存稿的 JSON、Markdown；当前内容与存储版本分别标注。清除网站数据会移除草稿和备份，重要内容请另存文件。

本地保存与导出均不是投稿、审稿任务提交、身份认证或链上登记。

联网与区块链边界

首页搜索及本地工作页读取本地材料。真实学者的详情页可能加载 ethers CDN，并向所选网络的 RPC 发起只读请求；点击来源链接会进入外部网站。

随包有测试网配置，没有主网部署清单。默认选网仅在主网清单缺失时选择测试网，且显示明确提示。切换网络不代表部署成功，实际状态以读取面板为准。

本轮验证隔离外部请求，不核验当前真实 RPC、交易或公开数据源状态。

三个视角分别能做什么

  • 读者：搜索与消歧、查看档案、评分依据和收据、返回原搜索结果。
  • 审稿人：阅读明确标注的虚构示例材料，引用材料段落，填写、保存、恢复、导入和导出本地评议草稿。
  • 投稿人：填写资料、核对缺项、保存或恢复草稿，导出本地材料清单；没有向期刊发送材料。
