# AIA 共享材料引擎

从既有 ARA 工作台提取的材料归档、PDF 提取、主张解析及规则预检，供真实协作产品与旧原型共同使用。引擎不负责账号、材料授权、付款或科学结论验收；这些边界由调用方实现。

从仓库根目录运行 `npm ci` 安装锁定依赖。`aia/app` 使用服务端会话和 SQLite；旧 `commission-demo` 保留演示身份及模拟结算，不能直接用于多人生产服务。

- `lib/research.mjs`：保留文件原件、SHA-256 和目录清单，规则式材料检查；不执行上传代码。
- `lib/pdf.mjs`、`lib/pdf-worker.mjs`：独立进程提取 PDF 文字，12 MB / 200 页 / 20 秒限制。扫描 PDF 不提供 OCR。
- `lib/zip.cjs`：现有 ZIP 打包器。

材料预检不是创新性评审、官方 ARA Seal 或研究真实性证明。自动生成的导航及主张文件保留生成来源。
