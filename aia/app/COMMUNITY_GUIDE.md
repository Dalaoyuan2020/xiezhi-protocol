# 知行社社区运行说明

社区在既有 `aia/app` 上运行。`/workspace/` 对游客展示 Idea、Attention、Act；`/ui/` 仍是默认彩色搜索首页，工作台切换入口保持原位置。h.ai v0.11.1 源码包仅用于参考授权方式，没有修改 h.ai 线上站。

## 启动与升级

在仓库根目录 `npm ci`、`npm start`。需要 Node.js ≥24.13.0；学者评分与管理员审稿资格检查还需 Python 3。复用原 `AIA_APP_DATA_DIR`、`AIA_ORIGIN` 与服务端 `.env`；先停止服务并备份完整数据目录再更新。新表自动创建，既有账号、研究、任务与原件保留。请同时复制 `aia/app/data/`、`public/community.js`、`lib/` 和 `brand/zhidian-coin-256.png`。

管理页仍为 `/admin/sources/`，入口不加入普通前端菜单。新增“评审模型 A/B”两个槽，分别填写 HTTPS 基础地址、模型名及访问密钥。支持兼容 chat completions 与 JSON 输出的模型；默认示例仅供填写参考，未强制选择服务商。按照用户最新决定，本版不展示 Bastet。

两槽没配齐时不发出任何模型请求，显示“未配置”；同一接口同一模型不能作为两份独立意见。地址限制为公网 HTTPS 443，无 URL 内凭据、查询参数和重定向。API key 仍在现有 AES-GCM 配置内，只有非密钥的地址和模型名可供管理员编辑回显。

**回滚说明**：本版会在 `source-config.enc` 中加入 `LLM_A/B_*`。旧版不认识这些字段时会拒绝读取，且保留原文件。回滚旧代码时应恢复配套配置备份，连同 `source-config.key` 一起恢复；不能删除解密密钥来“修复”。不要删除数据库或 Docker 数据卷。

## 三个区的边界

**Idea**：原件默认私有。作者手动授权后，社区仅公开标题、摘要、作者名、版本指纹及预评审状态；合格审阅者领取后才获得材料权限。双评审只发送所选版本的有界文本；归档文件哈希重新校验，记录模型、耗时、输入与响应指纹。每人每五分钟最多四次、全站最多两项并发；同一版本的同时点击合并为一次。

**Attention**：两个模型逐字段一致才给该字段结论；任何分歧不合成总体结论。作者授权后，分歧进入“门槛复核”，与正式审稿分开。正式门槛为绑定同一版本的本地材料可检查度至少 60/100，且双模型一致为低/中风险。门槛复核完成后，同版本重评达到门槛可进入正式队列；修订研究也可按新版本重新申请。上述规则衡量材料与预评审意见，不是科学真实性证明或 ARA Seal。

领取社区审阅须有独立核验的学术身份及至少 750 分；不能靠手填档案、分数或钱包签名解锁。初版核验由服务器维护者执行，记录依据且七天后失效。既有定向私有协作审阅继续保留，不表示社区审稿资格，也不自动奖励审稿廌点。

**Act**：首次启动从可追溯的 OpenAlex 快照生成 10 道作者列表核对题。它核对公开元数据，不认定真实学术身份。三名不同担保人作答，yes/no 至少两票才产生多数；unsure 不作肯定或否定。与多数一致且通过暗题核对的回答记 +3 廌点，每人北京时间每月最多 30 廌点。同一担保人与其多个 Agent 共用名额。

20% 的来源可核对题作为暗题，由服务端私密随机密钥选择；源码和公开 API 不含暗题标记。题目按“题型、作者 ID、论文 ID”去重，重新抓取同一材料不会变成可重复领奖的新题。这不能证明多个账号属于不同自然人，仍需持续身份治理。

论文复现使用原有作者、执行者、核查者三人分离流程，独立验收后 +8；证据核对 +3，运维 +2。工作符合约定但科学结果不一致仍可验收。廌点在 SQLite 幂等记账，明确标注“链下记账，待上链”，没有自动发主网交易或虚构回执。

## 更新真实任务来源

默认启动不联网。种子保留公开证据链接、时间依据、源快照 SHA-256 和必要摘录，不携带私有缓存路径或凭据。可在仓库根目录执行：

```sh
# 从已有真实缓存重新生成来源快照，先检查差异
node aia/app/scripts/seed-act-tasks.mjs --from-cache --snapshot-only
# 显式更新三个固定学者来源（最多三条上游请求）
node aia/app/scripts/seed-act-tasks.mjs --refresh --snapshot-only
# 导入当前来源快照；部署时指定原服务端数据目录
node aia/app/scripts/seed-act-tasks.mjs
```

目前是首批十题加既有论文任务，不是无限自动补题服务。作者发布摘要时，可另行勾选将文中 DOI 交给 Crossref 核对。服务端校验归档与授权后后台检查最多三个 DOI，只在收到真实 HTTP 404 时生成公开待核对题；题目只带 DOI、来源和检查指纹，不带作者账号、稿件信息或原文。404 表示该次查询未收录，不代表文献不存在。超时、429、服务异常不出题，原始响应保留在私有检查记录；同一版本不自动重复请求，同一 DOI 跨研究也只生成一题。已生成的公开核对题在撤下摘要后保留，这点会在授权时说明。

## 审稿资格维护

维护者应先通过可信渠道核对账号本人和学术档案。不得以公开搜索结果、任意人的档案编号或未验证邮箱替代本人证明。确认后，在服务器设置好 `AIA_APP_DATA_DIR`、评分所需的 OpenAlex 凭据及 Python 环境，再运行：

```sh
node aia/app/scripts/reviewer-access.mjs --user USER_ID --author A_OPENALEX_ID --identity-checked --evidence '已核对的身份依据及可复核记录位置（至少20字）'
# 撤销
node aia/app/scripts/reviewer-access.mjs --user USER_ID --revoke
```

命令实际调用当前 v2 评分器，失败不写资格，不接受客户端自报分。核验依据仅保留在私有数据库；公开视图仅显示是否有资格。此 CLI 不是自动身份认证系统。

## Agent 与验收

授权在个人页“我的 Agent”创建，固定七天，只授予所选能力，凭据仅显示一次。机器可导入并检测材料、回答核对题、读取指定任务材料并交付；不能进行人类审稿、验收或继续签发授权。记录同时保存 Agent 名称和担保人，交付指纹绑定执行者信息。接口与示例见 [AGENT_GUIDE.md](AGENT_GUIDE.md)。

运行 `npm test`、`npm run test:ui`。模型一致、分歧、失败等测试使用明确的测试响应，不以此宣称真实供应商已调用成功；真正接通状态需管理员保存配置后用获授权材料验证。浏览器验收使用独立数据目录，不向正常账号插入演示材料。
